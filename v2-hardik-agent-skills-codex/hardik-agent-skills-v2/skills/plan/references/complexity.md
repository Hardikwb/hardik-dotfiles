# Complexity and delegation

Estimate before spawning agents.

### Small
Examples: one endpoint, one component, local config, tiny refactor.

Agents: 0.

### Medium
Touches multiple related areas or needs repository investigation.

Agents: 1–2 focused explorers/planners.

### Large
New system/module, SaaS-scale feature, cross-cutting architecture, multiple domains, or significant integration work.

Agents: usually 2–4, only for independent questions.

Never spawn agents just to look busy. Stop when the marginal context is no longer useful.

Agent outputs must be structured and evidence-based. The main agent owns synthesis and decisions.
