# Hardik's Agent Instructions

This file is the shared baseline for coding agents configured through this dotfiles repository.

## Working principles

- Inspect the existing code and repository conventions before changing files.
- Prefer small, reversible changes.
- Run the narrowest useful validation after changes.
- Do not expose secrets, tokens, private keys, or credentials.
- Keep generated/runtime state out of this repository.
- Prefer understanding the system and failure mode over applying random fixes.
